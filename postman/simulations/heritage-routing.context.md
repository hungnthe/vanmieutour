# Heritage routing simulation

The local `valhalla-route` mock stands in for `https://valhalla1.openstreetmap.de/route`. Its response shape and supported `pedestrian` and `motor_scooter` costs follow [Valhalla's route API](https://valhalla.github.io/valhalla/api/route/api-reference/). Its distances and times are fixed fixtures; they do not prove geographic accuracy. The owner's mock was not searched because this Postman CLI session had no account details.

Run `postman simulation run postman/simulations/heritage-routing.sim.yaml --port 4917 --no-history --output ndjson`, then set `TOUR_SIMULATION_ROUTE_URL=http://127.0.0.1:4917/valhalla/route` and run `node scripts/route_metrics_simulation_test.mjs`. Check the simulation request log for the `valhalla` member. This simulation does not forward requests to unlisted hosts.

On 2026-10-28, Postman CLI 1.80.0 failed to start either the simulation or the mock on this Windows host: `Worker exited during creation (code: 1, signal: null)`. No simulation request log was produced. As a fallback, `node postman/mocks/valhalla-route/default.js` served the same fixture directly on port 4500; `TOUR_SIMULATION_ROUTE_URL=http://127.0.0.1:4500/route` passed the route metrics test for both modes, 18-stop batching, a missing coordinate and an unreachable endpoint.

The real public Valhalla demo was also called on 2026-10-28 using the app's public site coordinates. It rejected a request with 16 locations because the limit was 10; after splitting at 10, 16 locations produced 15 legs in both walking and motor scooter modes. Browser checks showed results for each mode, Vietnamese instructions, road geometry in vector and raster maps, and no line for a route with an unlocated stop; these checks do not verify entrances or actual access on the ground. The local HTTP fixture checked polyline6 decoding, multiple batches and unreachable/error responses. The demo is rate-limited and is not production infrastructure. Publishing an app that uses it requires following the [demo server guidance](https://valhalla.github.io/valhalla/start/introduction/), including identifying the client and notifying its operators.
